    Install

    About a minute per bank.
    1. Plug the FM-1 in over USB-C and open fm1-editor.com in Chrome or Edge. Firefox WebMIDI is unreliable on Linux and Safari has none.
    2. Turn MIDI on and point it at the FM-1.
    3. Import DX7 bank, pick a file, then choose which of A, B, C or D to write it to.
    4. Hold SAVE on the FM-1. Without this the bank is lost when it powers off.

    Four banks fill slots A–D (1–32, 33–64, 65–96, 97–128). Presets already on the device in a bank you overwrite are replaced.

    The editor is open source and does more than import. If Chrome will not hand over the MIDI port, the repo also ships fm1_send_bank.py, which writes a bank over ALSA from a terminal with no browser involved.

    Install

    About a minute per bank. Four banks and you're done.
    1. Plug the FM-1 in over USB-C and open the FM-1 editor in Chrome or Edge. Firefox WebMIDI is unreliable on Linux and Safari has none.
    2. Turn MIDI on and point it at the FM-1.
    3. Import DX7 bank, pick a file, then choose which of A, B, C or D to write it to.
    4. Hold SAVE on the FM-1. Without this the bank is lost when it powers off.

    Four banks fill slots A–D (1–32, 33–64, 65–96, 97–128). Presets already on the device in a bank you overwrite are replaced.

    Format

    Two things that break hand-built banks, both handled here.

    Standard Yamaha DX7 32-voice bulk dump, 4104 bytes: F0 43 00 09 20 00 <4096> <checksum> F7. Two details matter.

    1. Checksum. M-VAVE's own dumps compute (-sum(4096 voice bytes)) & 0x7F, leaving the six header bytes out. The textbook Yamaha checksum, which includes them, gets rejected as "this file looks damaged".
    2. Names. Some original DX7 patches pad the patch name with 0x7F bytes. Strict parsers reject a bank containing those, so every name here is reduced to printable ASCII before writing.

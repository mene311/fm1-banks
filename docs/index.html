Thematic banks for the M-VAVE FM-1

The FM-1 holds 128 presets as four banks of 32. These are complete 32-voice DX7 banks, each built around one theme, drawn from public DX7 collections and filed so that a bank is worth using as a bank. Load four into slots A–D and all 128 slots are something you meant to have.

Install

Under a minute per bank, four banks fills the instrument.
  1. Connect the FM-1 over USB-C and open the FM-1 editor in Chrome or Edge. Firefox and Safari WebMIDI are unreliable or unsupported.
  2. Enable MIDI and select the FM-1 as the output device.
  3. Import DX7 bank, choose one of the files below, and pick a destination bank: A, B, C or D.
  4. Hold SAVE on the FM-1 to write it to flash. Without this the bank is gone at power-off.

Four banks fill slots A–D (1–32, 33–64, 65–96, 97–128). Presets already on the device in a bank you overwrite are replaced.

Format

Two things that break hand-built banks, and why these work.

These are standard Yamaha DX7 32-voice bulk dumps, 4104 bytes: F0 43 00 09 20 00 <4096> <checksum> F7. Two details matter.

  1. Checksum. M-VAVE's own dumps use (-sum(4096 voice bytes)) & 0x7F, the six header bytes excluded. A textbook Yamaha checksum, which includes the header, is rejected by the editor as "this file looks damaged".
  2. Names. Some original DX7 authors padded patch names with 0x7F. Strict parsers reject those banks, so every name here is stripped to printable ASCII before the bank is written.
